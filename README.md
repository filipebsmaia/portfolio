# filipebsmaia.dev

Personal portfolio.

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Sass** (indented syntax + CSS Modules)
- **Lucide React** (icons)

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
pnpm start
```
